# QMIS_Final

                                                                         🌍 Air & Water Quality Index Monitoring System

The Air and Water Quality Index Monitoring System is a web-based platform developed to monitor environmental pollution levels related to air quality (AQI) and water quality (WQI). Similar to greenhouse gas emission monitors, the system analyzes real-time data and sends alerts to government authorities if pollution thresholds are exceeded.
This platform is particularly useful for environmental agencies, industrial compliance officers, and public stakeholders to track environmental violations, ensure regulatory compliance, and promote a healthier ecosystem.

                                                                 🔧 Technologies Used
Technology	        Purpose
1) HTML5	      Web structure and layout
2) CSS3	        Page styling and responsive design
3) JavaScript	  Client-side interactivity and data processing
4) Firebase 	  Login, data storage, alert handling
5) ML         	AQI/WQI prediction models
