# QMIS_Final

                                                                         🌍 Air & Water Quality Index Monitoring System

The Air and Water Quality Index Monitoring System is a web-based platform developed to monitor environmental pollution levels related to Air Quality Index (AQI) and Water Quality Index (WQI). Similar to greenhouse gas emission monitors, the system analyzes real-time or simulated data and sends alerts to government authorities when pollution thresholds are exceeded. The platform is built using HTML5 for structuring the web pages, CSS3 for creating a responsive and clean user interface, and JavaScript to add dynamic functionality such as real-time data display, alert generation, and user interaction. Each module, including AQI monitoring, WQI tracking, analysis reports, and stakeholder messaging, is organized into separate web pages to maintain a modular design. This system is particularly useful for environmental agencies, industrial compliance officers, and public stakeholders to monitor environmental violations, ensure regulatory compliance, and promote a healthier ecosystem.

                                                                 🔧 Technologies Used
Technology	        Purpose
1) HTML5	      Web structure and layout
2) CSS3	        Page styling and responsive design
3) JavaScript	  Client-side interactivity and data processing
4) Firebase 	  Login, data storage, alert handling
5) ML         	AQI/WQI prediction models
